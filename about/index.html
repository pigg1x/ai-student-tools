About StudyAI Hub

StudyAI Hub started as a personal spreadsheet: a college student keeping track of which AI tools were actually worth using for coursework, and which were hype. It outgrew the spreadsheet.

How tools get listed

  • Every tool is used on real coursework before it gets a review here.
  • We note free-tier limits honestly, because "free trial" is not free.
  • Dead or paywalled tools get removed - listings are re-checked monthly.

How we make money

Some outbound links may be affiliate links. Rankings and reviews are never for sale, and a tool with no affiliate program can still top a category. Tools that pay nothing sit at number one in several categories on this site.

Contact

Found a great tool we're missing? A broken link? Reach out - the list improves because readers flag things.
